Rouché–Capelli Theorem: A system of linear equations AX = B is consistent (has solutions) if and only if the rank of the coefficient matrix equals the rank of the augmented matrix: ρ(A) = ρ(A|B). If ρ(A) ≠ ρ(A|B), the system is strictly inconsistent (no solution).
